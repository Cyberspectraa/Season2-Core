# Season 2 Core 0.4.0-alpha.4 — Postal Model Redesign

This release is intentionally presentation-only.

## Drop Box
- Three-cuboid public postal-column silhouette.
- 12x14x12 body, 14x2x14 cap, shallow front posting hood.
- Muted spectral red palette with a dark slot, restrained brass trim and cream envelope plaque.
- Posting slot appears only on the functional front and the directional top intake.

## Letter Box
- Four-cuboid squat personal mailbox silhouette.
- Low plinth, wide wooden body, oversized lid and shallow front retrieval door.
- Warm timber palette with brass latch and cream envelope badge.
- No posting slot on the top, sides, rear or bottom.

## Safety
- No Java class was recompiled.
- Horizontal-facing placement and blockstate variants are unchanged from the tested 0.3.3-alpha.3 build.
- Collision remains the existing full-block collision for this visual pass.
- Mail persistence, Drop Box queues, Letter Box ownership/storage, courier routing, Discord integration and Dragon Currency are unchanged.
