## Season2 Core 0.5.0-alpha.5 — Town Life

Minecraft 1.20.1  
Forge 47.4.x  
Java 17  
EasyNPC `>=7.11.0` and `<8.0.0`

### Highlights
- Integrated Town Life 0.7.1 directly into the Season2 Core source tree.
- Town Wand resident registration with real-bed home assignment and workplace assignment.
- Resident schedules with HOME / COMMUTING / WORK / ERRAND / SLEEPING states.
- Real vanilla bed sleeping through `SleepService` with no floor-sleep fallback.
- Hunger, energy, fun and social needs.
- Lightweight FOOD / TOOL / ARMOR service errands.
- EasyNPC/Minecraft remains responsible for physical movement, doors and stairs.
- Bound Spectral Mail courier is protected from generic Town Life control.
- Dragon Currency and Spectral Mail remain included and were regression-tested with Town Life enabled.

### Installation
Install the release JAR on both the Minecraft server and clients.

Remove any standalone Town Life JAR before installing this combined build.

This is an alpha build intended for the Season 2 server.
