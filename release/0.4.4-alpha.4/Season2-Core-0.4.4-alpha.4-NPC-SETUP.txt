Season 2 Core 0.4.4-alpha.4 - EasyNPC Setup

COURIER
1. Install the 0.4.4 JAR on server + clients (AutoModpack is fine).
2. Import `spectral_post_courier-0.4.4.npc.snbt` if it is not already visible as a bundled EasyNPC preset.
3. The NPC should use the supplied postman skin from the mod itself; no internet skin host is required.
4. As an operator, stand next to the NPC, talk to it, choose Post Office setup, then Bind this NPC as the courier.
5. Run `/mail courier status` to confirm.

BANKER
1. Import `dragon_bank_banker-0.4.4.npc.snbt` if it is not already visible as a bundled EasyNPC preset.
2. The banker opens the deposit-only Dragon Bank with `/dragonbank @initiator`.
3. The preset intentionally contains no fixed Home coordinates, so place it wherever your bank is.

Both presets are also bundled as third-party EasyNPC datapack presets in the JAR for EasyNPC 7.10.0-compatible discovery.
